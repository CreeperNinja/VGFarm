## Crop Console Commands

**Permission:** admin

```lua
vgfarm_crop <add/set> <"player name"/"steamID"/steamID64> <crop> <amount>
```

`add` = sets the action mode to add to the current amount, accepts negative values, minimum allowed is 0

`set` = sets the action mode to set the amount, minimum allowed is 0

`"player name"` = double quotes required if name has a space

`"steamID"` = double quotes required

`steamID64` = can be written normally 

`crop` = the name of the crop

`amount` = whole number values only
